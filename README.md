# Counter App

A simple Counter App built using React.

## Features
- Increment the count
- Decrement the count
- Reset the count to zero
- Prevents the count from going below zero
- Displays a message when the minimum limit is reached

## Technologies Used
- React
- JavaScript
- CSS
- Vite

## How to Run

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

## Project Description

This project demonstrates the use of React's `useState` hook to manage state and update the user interface dynamically.
